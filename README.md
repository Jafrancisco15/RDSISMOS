# RDSISMOS

Aplicación web experimental de **pronóstico sísmico probabilístico regional**. Combina Raspberry Shake QuakeLink con USGS ComCat y el feed USGS de las últimas 24 horas, actualiza la interfaz cada minuto y conserva una ventana histórica de 90 días.

## Funciones principales

- Selección del país objetivo entre más de 200 países y territorios.
- Panel de actividad local que muestra los eventos más recientes del país y su entorno, sin depender de que Raspberry Shake y USGS publiquen al mismo tiempo.
- Mapa por capas:
  - eventos ocurridos;
  - fallas activas;
  - zonas proyectadas;
  - eventos precedentes o “padres”.
- Cápsulas ETAS auditables: cada cápsula incluye el identificador del evento padre, probabilidad condicional, rango de magnitud, plazo, zona proyectada y resultado posterior.
- Seguimiento de cápsulas activas, cumplidas y vencidas para evitar mostrar solamente coincidencias favorables.

> **Advertencia:** la aplicación no predice con exactitud terremotos y no sustituye las alertas ni recomendaciones de las autoridades sismológicas y de protección civil.

## Fuentes de eventos

La ruta `/api/events` fusiona y deduplica:

- Raspberry Shake QuakeLink, formato de texto y FDSN Event;
- USGS ANSS Comprehensive Earthquake Catalog (ComCat);
- USGS GeoJSON `all_day`, recomendado por USGS para aplicaciones de visualización en tiempo real.

No se necesita clave API para estas fuentes públicas.

## Modelo de cápsulas

La versión actual utiliza un núcleo **ETAS espacio-tiempo simplificado**:

- productividad del evento padre: `K · exp[α(M − Mc)]`;
- decaimiento temporal de Omori–Utsu: `(t + c)^−p`;
- decaimiento espacial alrededor del evento padre;
- distribución de magnitudes Gutenberg–Richter.

La probabilidad mostrada es `1 − exp(−N)`, donde `N` es el conteo esperado integrado para la zona y el plazo de la cápsula.

El modelo se inspira en los trabajos de Yosihiko Ogata y en implementaciones de pronóstico ETAS evaluadas en el marco CSEP. Los parámetros actuales son generales y **todavía no están calibrados país por país**; esa calibración es necesaria antes de interpretar el resultado como un producto operacional.

Referencias principales:

- Ogata, Y. (1992). *Detection of precursory relative quiescence before great earthquakes through a statistical model*. JGR.
- Ogata, Y. (2011). *Significant improvements of the space-time ETAS model for forecasting of accurate baseline seismicity*. Earth, Planets and Space.
- Zhuang, J. (2011). *Next-day earthquake forecasts for the Japan region generated by the ETAS model*. Earth, Planets and Space.

## Fallas activas

La capa opcional de fallas utiliza la **GEM Global Active Faults Database**, publicada por Styron y Pagani (2020) y distribuida bajo licencia CC BY-SA 4.0. La cobertura no es uniforme en todos los países.

## Desarrollo local

```bash
npm install
npm run dev
```

Abra `http://localhost:3000`.

## Variables de entorno

```env
RASPBERRY_SHAKE_EVENTS_URL=https://quakelink.raspberryshake.org/events/query
```

La variable es opcional y permite sustituir el endpoint clásico de QuakeLink.

## Despliegue en Vercel

1. Importe el repositorio como proyecto Next.js.
2. No configure una carpeta de salida estática.
3. Despliegue sin variables de entorno, salvo que vaya a cambiar el endpoint de Raspberry Shake.
